# 失配定律: |Δ| 是 token 置信度的函数

推导: log p_i = z_i − LSE(z)。若 logits 受 iid 扰动 ε~N(0,σ²), 则
δ(log p_i) = ε_i − Σ_j p_j ε_j, Var = σ²(1 − 2p_i + Σ_j p_j²)。
对尖锐分布 Σp_j² ≈ p_i², 得 **E|Δ| = σ√(2/π)·(1 − p_i)** —— 与 (1−p) 成正比, 单一常数。

## 四组的常数对比

| 配置 | 拟合常数 c | 指数 | 由定律预测的 mean\|Δ\| = c·E[1−p] | 实测 mean\|Δ\| |
|---|---|---|---|---|
| 1.7B tp4 | 0.0675 | 0.935 | 0.01165 | 0.01165 |
| 1.7B tp1 | 0.0473 | 0.924 | 0.00812 | 0.00820 |
| 8B tp4 | 0.0779 | 0.906 | 0.00958 | 0.00988 |
| 8B tp1 | 0.0490 | 0.904 | 0.00596 | 0.00628 |

**含义**: c 是硬件/编译器的单一常数 (等价于 logit 扰动幅度 σ = c·√(π/2))。
给定任意模型/数据集的置信度分布, 无需上机即可预测 mean|Δ|、λ、序列级 σ 与验证-回滚开销。
tp1 的 c 明显小于 tp4 —— 与 all-reduce 阶跃一致; 8B 与 1.7B 的 c 接近 —— 说明常数是编译路径的属性, 不是模型的。
